Le Livre des Formules Magiques

Étudiez-le avant de partir : dès que vous aurez commencé votre aventure, vous n'aurez plus le droit de le consulter. Certaines Formules proposées en cours de route n'existent pas : les choisir vous coûtera des points d'Endurance pour rien. Les Formules qui nécessitent un objet restent sans effet si vous ne le possédez pas.

Rappel des règles

Personnage. Guerrier : Habileté = 1 dé + 6. Sorcier : Habileté = 1 dé + 4, mais il peut utiliser les Formules Magiques. Endurance = 2 dés + 12. Chance = 1 dé + 6. Vous partez avec une épée, 20 Pièces d'Or et 2 repas de Provisions.

Combat. À chaque Assaut, 2 dés + Habileté pour chacun : la Force d'Attaque la plus élevée inflige 2 points de dégâts. Vous pouvez Tenter votre Chance pour aggraver une blessure que vous infligez (+2 si Chanceux, −1 sinon) ou atténuer celle que vous recevez (−1 si Chanceux, +1 sinon).

Chance. 2 dés inférieurs ou égaux à votre Chance : vous êtes Chanceux. Chaque test vous coûte 1 point de Chance.

Repas. Vous ne pouvez manger que lorsque le texte le permet (un bouton apparaît). Si vous passez une journée sans manger, vous perdrez 3 points d'Endurance le lendemain matin.

Magie. Chaque Formule coûte des points d'Endurance, qu'elle réussisse ou non. Le coût est appliqué au paragraphe où mène la Formule.

Libra. Votre déesse peut vous aider une seule fois : revitalisation, guérison, ou secours lorsque le texte le propose.
